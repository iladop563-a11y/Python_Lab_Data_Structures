Опис
У програмі виконано практичні завдання з основними структурами даних Python:
списками (list);
кортежами (tuple);
словниками (dict);
множинами (set).
Також проведено порівняння швидкодії операцій зі списками, множинами та словниками.
Запуск програми
Встановити Python 3.
Завантажити файл Python_Lab_Data_Structures.py.
Відкрити файл у Visual Studio або іншому середовищі Python.
Запустити програму.
Результати виконання будуть відображені в консолі.
